Filament

An Obsidian-inspired interactive graph view for SwiftUI, packaged for reuse across projects, with the layout engine kept pure and fully unit-tested.

View on GitHub All projects

What it does

Force-directed layout

A deterministic, seeded spring-embedder that settles smoothly up to a few hundred nodes: note vaults, link libraries, tag maps.

Focus and explore

Pan, pinch to zoom, drag nodes and tap to focus. Everything outside the focused node's neighbourhood dims.

Search highlighting

Pass the nodes that match a search and Filament highlights them in the graph.

Your palette

Build a theme from your app's own colours, or leave it out and Filament follows light and dark mode automatically.

Try it

swift run FilamentDemo
swift test
