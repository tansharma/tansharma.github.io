Counter

A local-first token-usage dashboard for your AI-assisted coding sessions. How much have I burned in this 5-hour block, when does it reset, and what am I spending it on?

View on GitHub All projects

What it does

Usage at a glance

Session and weekly token totals across every agent you use, with a countdown to Claude Code's next block reset.

A measured ceiling, not a guess

Reads the rate-limit rejections Claude Code records in its own transcripts and reports the real 5-hour limit, with the sample count shown.

Where it all goes

A year-long activity heatmap, per-model tokens and estimated cost, per-project focus time, and a project-to-model graph.

Local and read-only

No network calls, no API keys, no accounts. Counter reads the logs Claude Code, Codex, Gemini CLI and OpenCode write to disk, and never writes to them.
