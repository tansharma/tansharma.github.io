Loom

Ideas in, scaffolds out. Loom takes a raw app idea, asks a few clarifying questions to pin down the goal, and weaves a set of LLM-ready project files.

View on GitHub All projects

What it does

A full scaffold

Agent instructions, project.md, a README, a dependency-ordered task list, post-v1 features and a ready-to-paste prompt for every task.

Local-first generation

If Ollama is running, Loom suggests your local model and writes the whole scaffold for free. Anthropic, Gemini and OpenAI work too.

Zero dependencies

Pure Python 3.9 standard library. Clone it and run it; there is nothing to install.

Never destructive

Loom won't touch or overwrite your existing files, and API keys are only ever read from your environment.

Try it

python3 -m loom
python3 -m unittest discover -s tests
